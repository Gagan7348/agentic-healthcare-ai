# Agentic Healthcare AI System - Documentation

Welcome to the comprehensive documentation for the Agentic Healthcare AI System.

## Overview

The Agentic Healthcare AI System is a comprehensive healthcare platform that provides:
- **ML Predictions**: Diabetes, Heart Disease, and Kidney Disease prediction
- **ASHA Mode**: Decision support for community health workers
- **Gemini AI**: AI-powered chat and medical report analysis
- **Multilingual**: Support for English and Hindi

## System Architecture

### Frontend
- **React** with Tailwind CSS
- Multilingual UI (English & Hindi)
- Real-time predictions

### Backend
- **FastAPI** REST API
- **Gemini AI** integration
- ML model serving

### Streamlit Apps
- Phase 1: Basic ML predictions
- Phase 2: Advanced features with ASHA mode
- Phase 3: Gemini AI integration

## Features

1. **Disease Prediction**: ML-based predictions for 3 diseases
2. **Patient Database**: Manage patient records
3. **ASHA Mode**: Community health worker support
4. **Voice I/O**: Voice input and output
5. **AI Chat**: Gemini AI-powered assistant
6. **Report Analysis**: Medical report parsing
